# 💻 Qorqud Portfolio

A modern, interactive personal portfolio website built with **HTML, CSS and JavaScript**.

## 🌐 Live Demo

👉 **[View Live Site](https://qorqudabdullaza.github.io/portfolio-website/)**

## ✨ Features

- 🎨 Glassmorphism UI design
- 🌊 Animated background with floating blobs
- ✨ Particle system animation
- 🖱️ Custom cursor glow effect
- ⌨️ Typing effect in hero section
- 🎵 Background music toggle
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎯 Smooth scroll navigation
- 📊 Animated skill cards
- 📝 Contact form with validation
- 🎭 Scroll reveal animations
- ⚡ Toast notifications
